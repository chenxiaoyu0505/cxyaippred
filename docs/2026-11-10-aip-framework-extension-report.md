## 2. 现有模型的准确表述

输入为一条肽序列。冻结的 ESM-2 t33 650M 生成每个 token 的 1280 维表示，两个 1280 通道 ResCNN 块处理后做掩码均值池化，拼接 694 维手工描述符，经过 512 维融合层和二分类 MLP 输出一个 logit。现有头约 20.95M 可训练参数，不含冻结的 ESM-2。手工特征包含 AAC、GAAC、DPC、CKSAAGP、PAAC、CTD 和 12 项理化量；不能把 694 维统称为“理化性质”。

可主张的设计动机：预训练表征提供上下文编码；卷积在残基表示上提取局部模式；描述符显式提供组成、间隔/转移和理化摘要；融合层学习它们的组合。**这些只是合理假设，不是模块已被证明有效的结果。** ESM 表示及 DPC/CKSAAGP/CTD 本身已含顺序信息，因此后续 CfC 提分也不能直接写成“原模型完全不懂顺序”。

## 3. 建议新增结构

```
原始肽序列 ─→ 冻结 ESM-2 ─→ 现有 ResCNN ─→ 残基池化 ─→ c [B,1280] ─┐
            ├→ 20 种氨基酸 one-hot ─→ CfC ─→ 最后有效状态 l [B,64] ─┼→ 融合 → logit
            └→ 现有 694 维手工描述符 ──────────────→ f [B,694] ────────┘
```

### 3.1 CfC 原始序列通路

- **输入**：与主表同一行号的标准氨基酸序列，one-hot 张量 `[B,L_raw,20]`，真实长度 `[B]`；填充位置不可参与状态更新。训练集目前只含标准 20 AA；推理时对非标准字符要明确拒绝或定义固定映射，不能默默变成别的残基。
- **单元**：第一版单向、单层、hidden=64、backbone_units=128、backbone_layers=1、`mode=default`、相邻残基的形式步长 `Δt=1`。输出为最后一个真实残基的状态 `[B,64]`。参数按 ncps 官方默认 cell 约 43,904；实际以 `sum(p.numel())` 为准，并登记 ncps 版本。这里的“时间”仅是序列位置，不代表真实生物时间。
- **目的**：检验原始残基顺序的逐位状态整合，能否在现有 ESM-CNN 与描述符之外提供稳定增量。不能预设它优于 GRU，也不能把门控轨迹直接解释为生物过程。
- **必需对照**：原框架；原框架加同样输入、同量级参数的 GRU；原框架加 CfC。三者使用相同训练/验证/测试划分、训练预算与预处理。CfC 单独分支作为补充诊断，不作为证明协同的唯一对照。

### 3.2 软融合 router

先实现直接拼接 `[c,l,f]` 的三通路模型，随后才加入 router。推荐**按样本的分支级软权重**，不做逐残基专家选择：用每条分支的归一化摘要生成 3 个 logit，令 `w=3·softmax(logits)`，融合向量为 `[w_c c, w_l l, w_f f]`。router 最后一层零初始化，初始 `w=(1,1,1)`；分类头仍接收三条分支的完整向量 `[B,2038]`。摘要可由各分支投影到 128 维后拼接，router 用小网络（例如 384→32→3），避免在约 3,000 条/折的训练子集上引入大容量门控。

router 的问题是**样本相关的融合**是否比固定拼接更有用；它是软门控融合，论文中无需把它称为稀疏 MoE。对照应包括直接拼接、全局可学习的固定三权重、按样本 router；必要时再与增加相近参数量的普通 MLP 比较。报告每条分支的权重分布、不同长度/类别下的分布和跨 seed 稳定性，但权重不能直接当作贡献或生物特征重要性。

### 3.3 SAT 的地位

SAT 是**训练目标策略**，不是推理时的第四条通路。优先在无 SAT 情况下判定 CfC 与 router 的架构贡献；结构定型后再做 SAT 关/开对照。若没有干净数据和可重复的抗噪收益，就把 SAT 留作可选训练策略，不在主模型图中声称其必需。训练中预测经 EMA 形成的软标签可能强化早期错误，必须同时报告校准与错误样本分析。

**当前实现（2026-11-10，α 语义）**：用户希望硬标签权重 `α` 在前几个 epoch 快速接近 `0.7`，后续缓慢、渐近地逼近而不在固定轮次到达。令 epoch `e` 从 0 计数，采用 `α_e=α_min+(1−α_min)·2^(−max(0,e−start+1)/τ)`，`α_min=0.7`、`start=2`、`τ=1.0`；等价 `β_e=1−α_e`。于是 `e=0,1` 只用硬标签；`e=2,3,4,5` 的 `(α,β)` 分别为 `(0.850,0.150)`、`(0.775,0.225)`、`(0.7375,0.2625)`、`(0.71875,0.28125)`，此后趋向 `(0.7,0.3)`。在 `e=1` 末以当前训练预测初始化逐样本教师 `q_i=p_i^(1)`；从 `e=2` 起仅使用上一轮已停止梯度的教师状态：`t_i^(e)=α_e y_i+β_e q_i^(e-1)`；每轮末更新 `q_i^(e)=ρq_i^(e-1)+(1-ρ)p_i^(e)`，`ρ=0.65`。该精确 `2^-s` 曲线尚未实测；`cv5_ema_ramp` 用的是旧 `exp(−s)` 近似（α=0.810/0.741/0.715…），不能把它当作精确版结果。须与固定 `α=0.7` 及 SAT 关闭对照；调参只看训练/验证协议，不能根据现有五折 test 反复挑选。

## 4. 实施前必须处理的协议问题

1. **ESM 特殊 token 与池化**：`src/esm_backbone.py` 返回 tokenizer 的 `attention_mask`，它包括有效的 `<cls>`/`<eos>`；`src/model_aip.py` 把该 mask 直接用于“残基均值池化”。先确认 tokenizer 行为，建立残基专用 mask。卷积及 BatchNorm 还可能受 padding 长度和批内其他样本影响：训练缓存固定按全表最大长度填充，而 `scripts/predict.py` 按推理 batch 的最大长度填充。需用“同一肽在不同 batch/padding 长度下的预测是否一致”检验并处理。修正后建立**新的基线实验 ID**并重跑所有对照，不能与旧 `cv5` 数字直接比较。
2. **手工特征尺度**：`src/data_io.py` 缓存原始 694 维，模型直接拼接；长度、质量等维度与频率特征量纲不同。若采用标准化，均值/尺度只能由每折 train 拟合，保存到 checkpoint，val/test/推理复用；所有比较组必须采用同一变换，并重跑新基线。先检查零方差列和极端值。
3. **行号与输入契约**：one-hot、ESM 缓存、描述符和标签都以 `aip_all.csv` 行号对齐。现有手工特征缓存只检查形状，不校验序列指纹；扩展时加入缓存内容校验，避免同样行数但行序变化时静默错配。训练、验证、推理必须走同一序列清洗规则；不得给 CfC 的 `L_raw` 混入 ESM 特殊 token。保存原始长度并做 padding 不变性检查。
4. **checkpoint 兼容**：现有 `src/checkpoint.py` 的 v1 只能重建 `AIPHead`。新头要用新格式版本和 `model_type`、CfC/router 参数、氨基酸字母表、预处理统计与 ESM 层号；v1 加载应继续可用。`scripts/predict.py` 需按模型类型构造对应输入，不能只改训练脚本。
5. **结果边界**：当前随机五折的 test 已被用于多次架构讨论和实验比较，它们不再是一次性封存的独立测试。需要预先固定比较协议；最终泛化主张至少补序列相似性控制的划分，最好有后续收集且未参与选型的外部集。若日后做 PIP，须先独立清理其重复与跨集重叠，不可直接搬用旧 PIP 得分。

## 5. 逐模块证据矩阵：审稿人会问什么

| 模块/设计 | 合理假设 | 最低限度实验 | 允许的结论与边界 |
|---|---|---|---|
| ESM-2 冻结表征 | 提供有用的预训练残基表示 | 相同划分下与 one-hot/随机初始化的小型序列编码器比较；记录参数和训练预算 | 可说预训练表征改善预测，不能说学到了抗炎机制 |
| ResCNN | ESM 表示上的局部模式有额外价值 | ESM 均值池化+同等容量 MLP vs 现有 ResCNN；0/1/2 block 消融 | 只有稳定增益才说局部卷积有贡献；同时排除容量差异 |
| 694 维描述符 | 显式组成/理化摘要补充 ESM | 去掉全部描述符；按 AAC、GAAC、DPC、CKSAAGP、PAAC、CTD、12 理化量分组消融；控制维度和尺度 | 说明哪组对预测有增量；不能把相关性当生物因果 |
| 原始序列 CfC | 逐位状态整合提供互补信息 | 直接拼接框架 vs 加 CfC；同参数量 GRU/简单序列通路；长度分层及等组成打乱顺序诊断 | 若胜过加 GRU 才讨论 CfC 特定归纳偏置；打乱顺序只能做模型行为诊断 |
| router | 样本相关权重改善三分支融合 | 固定拼接 vs 全局权重 vs 样本 router；门控分布及遮蔽分支引起的预测变化 | 权重不是贡献；须用遮蔽后的变化验证分支确有增量 |
| EMA-SAT | 历史预测软目标可能改善泛化/抗噪 | 相同结构的关/开比较，多个 seed；仅 train 注入预注册比例标签翻转，val/test 保持原标签 | 若抗噪差异不稳定，仅能称可选正则策略；人工对称翻转不等同真实假阴性噪声 |

所有架构比较同时报告 AUPR、AUROC、MCC@0.5、MCC@val、F1、概率分布与校准（如 Brier/ECE），并提供每折、每 seed 的样本级测试预测。用同一条测试肽上的**配对差值**估计性能差异，报告区间而非只比较两组均值；同源簇存在时按簇做敏感性分析。参数量、训练耗时与推理耗时也需列出。若某模块只提高一个指标而损害其他指标，必须如实陈述权衡。

解释性分析应先在留出预测上做**分支遮蔽/重训消融**，再做残基替换或窗口扰动；改变序列后要重算 ESM 和手工特征，且区分真实序列与人工生成序列。归因图、CfC 门值、router 权重仅描述模型内部行为；若要宣称具体抗炎机制，需要独立实验或可靠的外部证据。

## 6. 给实现 agent 的执行顺序与验收

1. 建立新实验协议与基线：确认特殊 token 掩码、padding、描述符尺度和 checkpoint 兼容方案；锁定新 split/预处理版本。旧 `cv5` 留作历史，不覆盖。
2. 在不改动旧 `AIPHead` 行为的前提下加原始序列编码器与 CfC 分支；配置显式选择 `baseline` / `cfc_concat` / `gru_concat`。完成形状、长度、padding 不变性、行号对齐、保存/加载/预测一致性的测试。
3. 先用验证集做有限调试，固定超参，再运行同一协议的五折多 seed 对照；只在这一步后判断 CfC 是否进入候选主模型。
4. 如果 CfC 有稳定增量，再加入 `cfc_router` 与固定权重对照；记录三权重、分支遮蔽的 held-out 预测及样本级结果。若 router 没有可靠增益，主模型使用更简单的直接拼接。
5. 对选定结构单独评估修正版 SAT；完成序列相似性控制划分和可取得的外部验证，再组织论文主表、消融表与局限性。

验收标准不是“新模块必须提分”，而是每项结论都能从固定划分、配置、checkpoint、样本级预测和预先指定的比较重算；结果若不支持某模块，就删去该模块及相应主张。

## 8. ProtT5 与 router 的后续决策门槛（2026-11-10 补充）

用户提出再引入 ProtT5 编码并由 router 门控。该设想先作为**候选表征实验**，不自动纳入第 3 节的主模型。应使用冻结的 ProtT5 **编码器**提取表示，先比较 ESM-2 单独、ProtT5 单独、两者固定融合；确认 ProtT5 对同一留出样本带来稳定增量后，再比较固定融合与按样本 router。最后才评估 CfC、ProtT5 与 router 的联合模型，避免一次增加三个因素而无法归因。若两种蛋白语言模型错误高度重合、联合后无增益或成本不成比例，不加入 ProtT5/router。

高影响力期刊中的相关经验并不支持单纯堆模块：[PeptiVerse，Nature Communications 2026](https://www.nature.com/articles/s41467-026-74167-w)在多种肽性质上强调固定表征质量与数据划分，并发现不同下游分类头的差异通常较小；[PTM-Mamba，Nature Methods 2025](https://www.nature.com/articles/s41592-025-02656-9)用门控结合 ESM-2 与专门处理翻译后修饰 token 的通路，门控所融合的信息有明确差异；[InterPLM，Nature Methods 2025](https://pubmed.ncbi.nlm.nih.gov/41023434/)说明可以分析蛋白语言模型内部特征，但其稀疏自编码器并不是本项目必须新增的预测模块。[NeuroPpred-PSCG，Journal of Chemical Information and Modeling 2026](https://pubmed.ncbi.nlm.nih.gov/42438422/)以 ProtT5 和结构特征门控融合，并报告消融与稳健性；任务和特征与本项目不同，不能直接转移其性能结论。

若做 ProtT5/router，论文证据至少包括：相同 split/seed/训练预算下的表征替换与融合对照、两个编码器的错误重合率、固定权重与样本门控对照、按长度/相似性簇的分层结果、参数/缓存/推理成本。router 权重只能视为模型内部路由行为；须结合留出样本的分支遮蔽和重训消融核实增量，不能将其解释成某个编码器揭示了抗炎机理。
